## Product decision

The upgrade stays focused on translation quality and writing style. It does not add subtitle, speech-to-text, OCR, history, or generic AI tools. Groq remains primary; Apple Local remains the offline/failure fallback; Gemini remains optional.

## Findings to fix

### P0 — trust and accessibility

- Avoid reading API keys merely to render status or app startup state.
- Move from ad-hoc signing to a stable signing identity before commercial distribution; Keychain access on macOS is governed by code identity and item access control.
- Bring routine toolbar controls to 28×28 pt and every clickable control to at least 20×20 pt.
- Add Vietnamese accessibility labels to source/result editors and every icon-only action.
- Expose the shortcut recorder as a focusable, actionable control with role and value.
- Declare selected tabs and busy/error states semantically.
- Use an appearance-aware caret instead of a hard-coded black caret.
- Make `⌘Return` translate immediately; show Cancel while translating and Retry on terminal failure.

### P1 — flow and adaptability

- Show the detected source language without adding a new navigation level.
- Lead provider feedback with the result: “Đang dịch”, “Đã dịch bằng Groq”, “Đang dùng Apple Local dự phòng”; keep technical details secondary.
- Preserve the user’s existing clipboard across selected-text Copy/Paste automation.
- Keep two columns when space allows and stack source/result in a narrow window.
- Reduce repeated window movement while typing and honor macOS Reduce Motion.
- Finish Vietnamese-first copy: use “Dán”, “Sao chép”, “Thử lại”, and consistent sentence casing.

### P2 — translation quality without more requests

- Keep Dịch nhanh context-free; optional task context belongs to the existing Văn phong request, not a second AI pass.
- Add protected terms/glossary rules to the same Văn phong request so names, product terms, and fixed phrases remain unchanged.
- Keep meaning, factual certainty, numbers, names, formatting, and target language as non-negotiable prompt constraints.
- Test prompt contracts for empty context, populated context, protected terms, and user style presets.

### P3 — polish

- Put raw preset prompts behind “Nâng cao”; show plain-language controls and examples first.
- Centralize visual tokens and reusable editor/control patterns.
- Provide a compact setup/diagnostics path for Groq key, Accessibility permission, Apple Local availability, and shortcuts without forcing onboarding on existing users.

## 9/10 acceptance criteria

- Core and build scripts pass; the installed executable path/version/build/checksum are recorded.
- No API key is printed, backed up, logged, or read simply to display status.
- Quick and Style translation work with Groq; missing key, invalid key, quota error, offline state, and Apple Local unavailability have clear recovery text.
- `⌘C`, `⌘V`, `⌘A`, `⌘Return`, Escape, and all three configurable global shortcuts behave as documented.
- Source/result remain usable at narrow and wide sizes; long results scroll only after the maximum comfortable height.
- Light, dark, Reduce Motion, keyboard-only, and VoiceOver flows pass `Docs/RELEASE-CHECKLIST.md`.
- Every click target is at least 20×20 pt; routine controls use 28×28 pt.
- Dịch nhanh has no context/glossary control or hidden guidance; optional Style context and protected terms do not add a second Groq request.
- No regression to Apple Local fallback, favorite language pairs, favorite style presets, auto-translate debounce, copy/replace, or Vietnamese UI.

## 1.9.1 simplification and prompt audit

- Removed the context/glossary control and its request path from Dịch nhanh. The primary flow is again input/paste → automatic translation → copy.
- Kept context and protected terms as progressive disclosure in Văn phong AI only.
- Replaced vague or conflicting style constraints with explicit inference boundaries, observable language features, and factual/pragmatic invariants.
- Removed unwanted greeting tokens from the active peer prompt to avoid lexical priming.
- Added deterministic migration and prompt-contract tests; see `Docs/PROMPT-AUDIT-1.9.1.md`.

## Reference principles

- Apple HIG Accessibility: macOS default control size 28×28 pt, minimum 20×20 pt; label controls and support assistive technologies.
- Apple HIG Designing for macOS: support resizable windows, keyboard shortcuts, familiar menu commands, and comfortable information density.
- Apple HIG Focus and Selection: rely on system focus effects and avoid moving focus unexpectedly.
- Apple Security documentation: store small secrets in Keychain and maintain a consistent code identity for reliable authorization.
